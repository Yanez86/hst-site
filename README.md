# hst-site

Il sito di **Happy Squid Inc.**: giochi fatti in casa.

Pagine:

- `index.html`: la pagina principale (Runess, F.U.P., Happy Squid Game, Fudo e i disegni)
- `bio.html`: chi siamo
- `contatti.html`: scrivici (il modulo per ora non invia nulla: serve un indirizzo email o un servizio che inoltri i messaggi)
- `disegni.html`: il muro dei disegni di Yanez

Tutte le immagini sono nella cartella `img/`. Il sito è fatto solo di file HTML: non serve nessun programma per costruirlo.

## Pubblicarlo con GitHub Pages

Su GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ramo `main`, cartella `/ (root)`.
Dopo un minuto il sito è online su https://yanez86.github.io/hst-site/
